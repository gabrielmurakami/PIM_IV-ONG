## 📄 Sobre o Projeto

Este repositório contém o código-fonte desenvolvido para o **PIM IV** (Projeto Integrado Multidisciplinar). O objetivo principal é fornecer uma solução tecnológica para automatizar e facilitar a gestão interna de uma Organização Não Governamental (ONG).

O sistema foi pensado para ajudar a instituição a ter mais controle sobre seus processos diários, liberando tempo para que o foco continue sendo o impacto social.

## ✨ Funcionalidades Principais

- **Gestão de Voluntários:** Cadastro, atualização e controle de disponibilidade.
- **Controle de Doações:** Registro de entradas de recursos (financeiros e materiais).
- **Gestão de Assistidos:** Cadastro e acompanhamento das famílias/pessoas atendidas pela ONG.
- **Autenticação:** Sistema de login seguro com controle de acesso (Administrador / Usuário padrão).

## ⚙️ Pré-requisitos

Antes de começar, você precisará ter as seguintes ferramentas instaladas em sua máquina:

- [Git](https://git-scm.com)
- Dependendo da stack: [Node.js](https://nodejs.org/en/) ou [.NET SDK](https://dotnet.microsoft.com/download)
- Uma IDE de sua preferência (ex: [VS Code](https://code.visualstudio.com/) ou Visual Studio)

## 🛠️ Como Executar o Projeto

```bash
# 1. Clone este repositório
$ git clone [https://github.com/gabrielmurakami/PIM_IV-ONG.git](https://github.com/gabrielmurakami/PIM_IV-ONG.git)

# 2. Acesse a pasta do projeto no terminal
$ cd PIM_IV-ONG

# 3. Instale as dependências (Exemplo genérico)
$ npm install  # (se for Node.js)
# ou
$ dotnet restore  # (se for C#)

# 4. Execute a aplicação
$ npm start  # (se for Node.js)
# ou
$ dotnet run  # (se for C#)
```
